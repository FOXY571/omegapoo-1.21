Have you ever wondered how to poop in Minecraft? Well with this mod, now you can!

 

How it works:

- Collect toilet paper using sugar cane

- Use the toilet paper to poop

- Poop can be used to make blocks (or eaten)

- Blocks are very decorative

 

This mod was originally supposed to serve as a way to lower your hunger when needed, but it is ever-expanding.

 

Soon, I will update the mod to the newer versions of Minecraft. I'm still deciding whether or not I want to make a Fabric port.

 

Feel free to use the mod in your modpacks!
